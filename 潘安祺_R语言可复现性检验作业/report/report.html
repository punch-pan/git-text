📌 研究背景与选题说明

原文献概况

Christensen et al. (2018) 发表于 European Journal of Personality，探究开放性人格与语义记忆网络结构。共516名被试，根据开放性潜变量中位数分为高/低组（各258人），利用余弦相似度+TMFG算法构建语义网络，提出三个核心假设：
H1：高开放性组ASPL（平均最短路径长度）更低；
H2：高开放性组CC（聚类系数）更高；
H3：高开放性组Q（模块度）更低。
原文结论：三项假设均获支持，开放性人格与语义记忆网络显著关联。

选题原因
  • 数据与代码完全公开于OSF（osf.io/craky/）
  • 被2026年Nature Multi100多分析师项目纳入，有外部参照
  • 方法匹配课程所学（传统统计 + 网络分析）
研究意义

检验原研究的计算可复现性与结论稳健性，探索网络分析偏差核心成因，践行心理学开放科学理念，为量化研究提供严谨复现范例。

⚙ 复现设计与方法

数据与环境

数据来源：原作者OSF平台清洗后完整数据集（N=516），严格按原文规则分组（低/高组各258人），未修改样本。
分析环境：R 4.5.2，设置随机种子 set.seed(2025)，保证自身可复现。
核心复现：100%复刻原文流程 — 描述性统计、Pearson相关、独立样本t检验、McNemar检验、TMFG网络构建与ASPL/CC/Q计算。
创新方法：采用最小生成树（MST）代替TMFG，检验结论对算法的敏感性。

评级标准（百分误差PE）

\[ PE = \frac{|复现值 - 原文值|}{|原文值|} \times 100\% \]
▪ 完全一致：PE = 0%
▪ 次要偏差：0% ＜ PE ＜ 10%
▪ 主要偏差：PE ≥ 10%
推论一致性：以α = 0.05为判断标准，对比复现结果与原文的统计推论方向是否一致。

核心R代码片段（网络构建与指标）
# 余弦相似度 + TMFG过滤 (NetworkToolbox)
cos_low <- cosine(low_mat, addConstant = .01)
net_low <- TMFG(cos_low)$A
g_low <- graph_from_adjacency_matrix(net_low, "undirected")
# 连通分量处理：提取最大连通分量 (规范做法)
if(!is_connected(g_low)) {
  cl <- components(g_low)
  g_low <- induced_subgraph(g_low, which(cl$membership == which.max(cl$csize)))
}
aspl <- mean_distance(g_low)
cc <- transitivity(g_low, type = "global")
q <- modularity(cluster_louvain(g_low))

🔍 偏差与不一致成因分析

原文献开放性问题
  • 未明确网络连通性处理规则（是否提取最大连通分量）→ 复现时按规范提取，改变节点/边数，影响ASPL/Q。
  • 未设置随机种子 → Louvain社区检测结果波动，模块度不稳定。
  • 未注明NetworkToolbox包版本 → TMFG输出细微差异。
  • 缺少分析说明文档，部分细节依赖推测。
复现过程的合理差异

除网络预处理采用学界通用规则（提取最大连通分量）外，其余完全复刻原文，无操作失误。软件包版本（igraph/NetworkToolbox）与原文可能不同，属自然变异。

方法本身特性

经典统计（t检验、卡方）算法固定，复现极稳定；而语义网络分析存在大量分析选择：相似度阈值、过滤算法（TMFG vs MST）、指标计算公式差异等，结论对分析路径高度敏感。

💭 学习反思与整体结论

实操学习收获

✔ 完整掌握R语言数据清洗、传统统计、语义网络构建及指标计算的全流程。
✔ 深刻体会“固定随机种子 + 规范注释 + 标注软件版本”对可复现性的关键意义，好习惯比复杂代码更重要。
✔ 开放科学不只是公开数据与代码，还需要充分披露分析细节（预处理规则、算法参数等）。

整体研究结论
  • ✅ 基础统计（描述性统计、相关、t检验、McNemar、φ系数）可良好复现，PE均低于10%。
  • ⚠️ 语义网络核心假设稳健性不足：原方法下仅33.3%推论一致；更换MST算法后全部矛盾，说明结论依附于特定的分析路径。
  • 📌 网络分析类研究必须开展多算法/多路径稳健性检验，避免单一分析带来的假阳性结论。
课程与行业建议

课程建议：补充网络分析常见易错点（连通分量处理、聚类系数类型区别、软件版本兼容），帮助学生提前规避复现陷阱。
行业倡议：心理学网络分析研究应完整标注分析全流程，主动提供多算法结果，全面落实开放科学要求，提高研究可信度。
